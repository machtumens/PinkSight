What to re-connect when you redesign this file. Every dynamic element carries a data-wire attribute naming its source.

This file is a MOCK design playground. Nothing talks to the sidecar. Redesign freely, keep the data-wire annotations, then map them back to the real React app (desktop/src) + Python sidecar using the tables below.

4 · Invariants a redesign MUST preserve

  • 🔒 Routing-only picker. Shows which harness owns a (cohort, modalities) tuple and whether it is WIRED — never a per-organ number, never a Run button. 0/10 organs have a single-patient forward path (the honest ceiling).
  • 🔒 Every payload tagged. A model output never appears as a bare number — it is MOCK- or "SYNTHETIC — NOT A RESULT"-tagged, and always sits inside its uncertainty band. Abstention is shown, not guessed.
  • 🔒 Forbidden copy (claim ledger): early/pre-detection · growth rate · doubling time · kinetics · screening · cross-institution. Say characterisation / localisation and Ki-67 / aggressiveness.
  • 🔒 Phantom is synthetic. Labeled "not patient data"; the phase slider's enhancement is a display axis, never a kinetics claim.
  • 🔒 Honest performance. Imaging-only AUROC (0.567) shown alongside the clinical anchor (0.708) — the ceiling is never hidden.
